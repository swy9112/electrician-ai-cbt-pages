# 전기기사 AI CBT — 공개 실행 화면

전기기사 개인 학습용 CBT의 **공개 배포 전용 저장소**입니다.

이 저장소에는 다음 파일만 포함합니다.

- 정적 HTML/CSS/JavaScript 실행 화면
- 창작 더미 문제
- PWA 및 GitHub Pages 배포 설정

## 학습 모드

- **틈새학습:** 등록한 전체 문제은행에서 과목을 고르고, 회차와 관계없이 5·10·20문제를 날짜별로 조합해 풉니다.
- **실전 모의고사:** 연도와 회차를 고른 뒤 실제 필기시험 기준인 100문제·150분으로 풉니다.
- **회차 완료 기록:** 실전 제출 후 연도·회차별로 `1회 완료`, `2회 완료`처럼 기기에 누적 표시합니다.
- **오답 보완학습:** 틀린 문항을 과목별로 모아 다시 풀고, 맞히면 보완 목록에서 제외합니다.

두 모드 모두 기본적으로 한 화면에 한 문제씩 표시하며, 데스크톱에서는 2문제 보기로 변경할 수 있습니다. `문제은행 등록·교체`는 PDF를 직접 여는 기능이 아니라 Codex가 여러 PDF를 검수해 만든 하나의 JSON 문제은행을 등록하는 기능입니다.

## 중요한 데이터 분리 원칙

실제 기출문제, 복원문제, 정답, PDF, 응시 결과와 분석 데이터는 이 공개 저장소에 올리지 않습니다.
실제 문제은행은 배포된 화면에서 사용자가 보유한 JSON 파일을 직접 등록해 사용합니다. 문제은행은 해당 브라우저의 IndexedDB에, 답안 진행 상태는 localStorage에 저장되며 서버로 전송하지 않습니다. Safari의 사이트 데이터를 지우면 문제은행도 삭제되므로 원본 JSON은 파일 앱에 별도로 보관해야 합니다.

완료 횟수와 오답 목록도 해당 브라우저에만 저장됩니다. PC와 iPad 사이에 자동으로 동기화되지는 않습니다.

## 배포

`main` 브랜치의 `public/` 폴더가 변경되면 GitHub Actions가 GitHub Pages에 자동으로 배포합니다.

저장소의 `Settings → Pages → Build and deployment → Source`를 `GitHub Actions`로 선택하면 됩니다.

배포 주소:

<https://swy9112.github.io/electrician-ai-cbt-pages/>

## 실제 데이터 보관 위치

개발 원본과 개인 학습 데이터는 비공개 저장소 `electrician-ai-cbt`에서 관리합니다. 공개 화면을 수정할 때는 검토된 `cbt/` 실행 파일만 이 저장소의 `public/` 폴더로 동기화합니다.
